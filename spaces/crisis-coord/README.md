# CrisisCoord: Disaster Response Coordination

This space hosts the interactive Command Center for the CrisisCoord environment.
Coordinate response across 5 districts, manage resources, and save lives.

## How to use:
1. Input a JSON action in the text box.
2. Example: `{"action_type": "SURVEY", "location_id": "L1"}`
3. Observe the world state update and track your reward!
